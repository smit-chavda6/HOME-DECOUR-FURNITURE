PROJECT DESCRIPTION:
A complete full-stack e-commerce web application built for home decor furniture 
shopping. The platform features user authentication, product management, shopping 
cart functionality, order processing, and an AI-powered chatbot for customer 
support. Users can browse furniture across multiple categories, add items to cart, 
checkout, and receive AI-assisted customer service. Administrators can manage 
products, users, orders, and system settings through a dedicated admin dashboard.

================================================================================

KEY FEATURES:
1. User Registration & Login - Secure authentication with password hashing
2. Product Catalog - Browse furniture by category (Living, Dining, Bedroom, Office, 3D)
3. Shopping Cart - Add/remove items, persistent storage
4. Checkout & Orders - Complete order processing with order tracking
5. AI Chatbot - Google Gemini-powered intelligent customer support
6. Admin Dashboard - Manage products, users, orders, messages
7. Product Reviews - Rating and review system for products
8. Dark Mode - Theme switching with localStorage persistence
9. Responsive Design - Works on desktop, tablet, and mobile devices
10. Gallery - Interactive product gallery with 3D models
11. Blog & FAQ - Informational content for customers
12. User Profiles - Customer profile management and order history
